# machina-deid

Our entry for the Builders Buildathon track **Machina - CAD De-ID**: de-identify a 139.7 GB engineering CAD corpus
with consistent pseudonyms while keeping every file usable.

- Track page: https://www.joinbuilders.org/buildathon/tracks/machina-deid
- Brief (PDF): https://www.joinbuilders.org/buildathon/tracks/machina-deid/files/challenge.pdf
- Deadline: **Sunday 2026-11-22, 11:00 AM EST**

This repo holds context, design and code only. Raw input and anything derived from it with real identifiers
stays local and out of git.
